# 🧴 Cleaning & Fragrance Products Website

A modern Arabic RTL website for a cleaning and fragrance products factory, designed to provide customers with a simple and convenient way to browse products, add them to their orders, and send their order details directly through WhatsApp.

## ✨ Features

* 🌐 Arabic RTL interface
* 📱 Fully responsive design
* 🏠 Home page with modern sections
* 🏢 About Us page
* 🧴 Products page with categories and filtering
* 🛒 Shopping cart / orders system
* ➕ Add products to order
* ➖ Increase and decrease product quantities
* 🗑️ Remove products from orders
* 💬 Send orders directly through WhatsApp
* 📞 Display business contact information
* 📍 Contact page with location map
* 📩 Contact form
* 🎨 Clean and modern UI
* ⚡ Smooth user experience

## 🛠️ Technologies

* React
* Vite
* Tailwind CSS
* Redux Toolkit
* React Router
* React Icons
* JavaScript (ES6+)

## 📄 Pages

### Home

Introduces the factory and highlights featured products and the main benefits of the company.

### About Us

Provides information about the factory, its story, vision, and some company statistics.

### Products

Displays available cleaning and fragrance products with category filtering and the ability to add products to the order.

### Orders

Allows customers to review their selected products, manage quantities, remove products, and send the final order through WhatsApp.

### Contact

Provides the company's contact information, phone number, WhatsApp, email, location map, and a contact form.

## 🛒 Order Flow

```text
Browse Products
      ↓
Add Product to Order
      ↓
Review Order
      ↓
Adjust Quantities
      ↓
Send Order
      ↓
WhatsApp
```

## 🎨 Design

The website uses a clean color palette based on navy blue, cyan, light blue, and soft backgrounds to communicate cleanliness, trust, and freshness.

The interface is fully designed for Arabic RTL layouts and optimized for desktop, tablet, and mobile devices.

## 🚀 Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project:

```bash
cd YOUR_PROJECT_NAME
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
